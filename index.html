FINANCIAL CONTROLS & WORKFLOW AUTOMATION

Reconciliation & Operational Controls Platform

A deterministic control layer for reference-to-invoice and invoice-to-payment-to-ledger reconciliation. The Python / FastAPI core combines exact Decimal arithmetic, schema validation, stable-identifier matching, duplicate quarantine, period / currency / amount checks, persistent run and exception state, audit events and fail-closed report publication. Companion n8n orchestration adds CSV preflight, transport / HTTP failure classification, API contract verification and report-artifact checks. Project records: 53 passing core tests and 25/25 synthetic golden outcomes. Prototype—not a live production deployment.

DEPLOYED OPERATIONS APPLICATION

DriftOps — Operational Cashflow & Payout System

A deployed operational-finance application built to solve a practical visibility problem: hospitality income, expenses, cash / UPI / bank balances, advances and contractor payouts were fragmented across separate records. DriftOps brings these flows into one operating layer with structured categories, calculated balances, real-time ledgers, charts, CSV exports, authentication and role-based access. It replaces repetitive manual consolidation with a consistent operating view; no unverified hours-saved claim is made.
