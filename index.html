FINANCIAL CONTROLS & WORKFLOW AUTOMATION

Reconciliation & Operational Controls Platform

Problem: financial records can arrive in inconsistent files and formats, while a successful API response does not guarantee a valid reconciliation or usable report. Built a deterministic Python / FastAPI reconciliation core with exact Decimal arithmetic, schema validation, stable-ID matching, duplicate quarantine, period / currency / amount checks, exception state and audit events. Hardened the n8n intake to validate CSVs, classify transport / HTTP failures, verify the API response contract and check the downloaded report artifact. Project records report 53 passing core tests and 25/25 synthetic golden outcomes. Prototype, not a live production deployment.
